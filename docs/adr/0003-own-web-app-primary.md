# Our own web app is the primary product, the globe is secondary

The judged path is `web/`: AOI → burning activity calendar → anomalies → critical periods → this week vs history → 7-day risk. It works offline with vendored JS, and it answers the challenge directly. The gods-eye-view globe (fork of Bilawal Sidhu's MIT project, branch `space-apps-2026`) is a second act with a fire-only preset and the `get_fire_risk` / `get_burning_calendar` agent tools. Its upstream is a large codebase we don't control, and it's built around unrelated layers. If time runs short, the globe is cut first.
